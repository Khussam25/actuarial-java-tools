# Actuarial Java Tools
This repository contains Java-based utilities designed for financial risk assessment and statistical modeling.

## Project 1: Risk-Adjusted Return Calculator
A simple tool that calculates the expected value of an investment by factoring in a probability of loss (risk factor).

### How to Run:
1. Compile: `javac RiskCalc.java`
2. Run: `java RiskCalc`

### Skills Demonstrated:
* Java Syntax & Logic
* User Input Handling (`Scanner`)
* Fundamental Actuarial Math
